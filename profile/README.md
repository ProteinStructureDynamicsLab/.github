# Protein Structure and Dynamics Lab

[Telethon Institute of Genetics and Medicine (TIGEM)](https://www.tigem.it/) — Pozzuoli (NA), Italy

We study how protein structure and dynamics determine function, and we use that
understanding to engineer proteins with improved properties. Our work combines
molecular simulation, structure prediction and protein language models with
experimental measurement in a closed design–build–test loop.

## What's here

| Repository | What it is |
| ---------- | ---------- |
| [EvolvePro](https://github.com/ProteinStructureDynamicsLab/EvolvePro) | Fork of [mat10d/EvolvePro](https://github.com/mat10d/EvolvePro), kept in sync with upstream |
| [evolvepro_toplayer_analysis](https://github.com/ProteinStructureDynamicsLab/evolvepro_toplayer_analysis) | Model and hyperparameter search over PLM embeddings |
| [boltz](https://github.com/ProteinStructureDynamicsLab/boltz) | Fork of [jwohlwend/boltz](https://github.com/jwohlwend/boltz) for biomolecular interaction prediction |

Forks are kept for tracking upstream. Code we write ourselves lives in its own
repository so that it can be tested, versioned and cited.

## Using our code

Every repository we author states its license, its input formats and how to run
its tests in the README. If something doesn't reproduce, open an issue — that is
a useful bug report, not an imposition.
